# rick-and-morty-api

A API de Rick and Morty é uma API REST (ou algo semelhante) e GraphQL baseada na série de televisão Rick and Morty . Você terá acesso a centenas de personagens, imagens, locais e episódios. A API de Rick and Morty está repleta de informações canônicas, conforme visto na série de TV.
